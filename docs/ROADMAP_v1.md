# Evidence-gated roadmap v1

This roadmap incorporates the Paper 1.5 boundary. It does not count false-alarm
calibration, conformal methods, contracts, hashes, generic provenance, blind
regions, or local allow/hold/block as Paper 2.5 novelty.

## Gate 0 — complete infrastructure

Audit authoritative ATHENA sources and companion work; freeze RQs/novelty and
operational threat model; implement schemas, provider boundary, simulator,
kernel regression, FMS oracle/skeleton, OOS baselines, P0--P5,
enforcement/recovery, authenticated binding, confidentiality matrix, tests,
CI, registries, and draft preregistration.

## Gate 1 — restore zero-cost IBM observability

Obtain a valid accessible instance without putting credentials in Git. Repeat
authentication/backend/status/target/properties/queue/usage preflight. If safe,
run one separately labelled minimal connectivity smoke test.

## Gate 2 — run non-confirmatory pilot

Use one backend and the kernel workload. Measure job/shot/context variability,
metadata missingness, workload feasibility, and support-baseline behavior. Fix
window cadence/count and QPU budget from observed precision/cost, not tradition.

## Gate 3 — preregister and commit

Resolve every pilot-dependent placeholder, freeze analysis code/config hashes,
commit `PREREGISTRATION_v1.md`, and tag that commit before any confirmatory QPU
job. Failed kill criteria narrow claims before data collection.

## Gate 4 — confirm one complete causal chain

Prioritize real QPU controlled interventions, multiple temporal windows, one
closed kernel workload, then P4/P5 recovery. Only after that add a second backend
or full routing QAOA. All paper tables/figures are builder outputs from sealed
registries; no headline number is handwritten in LaTeX.
