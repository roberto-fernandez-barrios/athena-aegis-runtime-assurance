# Contributing

Please report reproducibility defects with the release tag, Python/OS/dependency versions, exact offline command and the failing check. Do not attach credentials, provider account/job identifiers, private keys or unredacted local records. Scientific interpretation questions are welcome through GitHub issues; security-sensitive reports belong in the private channel below.

Frozen evidence, historical code and published tags are immutable. Propose fixes in a new namespace or release, distinguish them from the campaign implementation and document their effect on observed verdicts. Documentation fixes should preserve numerical claims and stated limitations. A proposal for another study does not change this release's evidence.

Run `python scripts/verify_publication.py --output reproduced` in the locked environment. Source changes affecting public files require a reviewed manifest update and a new version; do not silently rewrite an archived release. Any acquisition work is outside this offline artifact.
