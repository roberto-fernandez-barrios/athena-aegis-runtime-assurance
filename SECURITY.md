# Security and private reporting

This is a research reproduction artifact, not a supported production assurance service. Numerical validation and file hashes do not authenticate a provider or establish a general safety guarantee.

Please report accidentally exposed credentials, private identifiers or integrity concerns privately to roberto.fernandez.b@deusto.es. Do not include secrets in public issues or pull requests. Send only the affected release/path and a non-sensitive description initially. No guaranteed response period or production support commitment is claimed.

The reproduction command is offline and requires no provider credentials. Do not add provider tokens or local account files to this repository. Published evidence is preserved; verified defects should receive a transparent advisory or corrected version.
